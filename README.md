# 🧠 Deep Learning End-to-End Projects  

Welcome to my **Deep Learning Repository!** 👋  

This repository showcases a collection of **beginner-to-advanced Deep Learning projects**, covering the full pipeline from **data preprocessing → neural network design → model training → evaluation → visualization**. Each project focuses on applying **neural architectures** to solve real-world AI problems.  

---

## 📂 Projects Included  

- 🖼️ **PROJECT1.** Basic Diabetes detection using NN
- 🧬 **PROJECT2.** Object Detection using Transfer Learning  
- 🐶 **PROJECT3.** Brain Tumor Detection from Scratch using CNN
- 🍽️ **PROJECT4.** Custom Image Classification using Transfer Learning
- 📸 **PROJECT5.** Image Recognition using PyTorch
- 🚶‍♂️ **PROJECT6.** Social Distance Monitoring using YOLOv8



> ⚡ Each project includes **data preprocessing, model architecture, training details, evaluation metrics, and visualizations**, making this repository a **complete DL reference**.  

---

## 🔑 Key Features  
- Covers **Core Deep Learning Domains**: ANN, CNN, RNN, LSTM, Transformers, and GANs  
- Implements **modern architectures** (LeNet, AlexNet, VGG, ResNet, Inception, LSTM, BERT, etc.)  
- Includes **Transfer Learning & Fine-tuning** techniques  
- Demonstrates **Data Augmentation, Dropout, Batch Normalization, Regularization**  
- Evaluation through **Loss curves, Accuracy metrics, Confusion matrices, AUC-ROC**  
- Each project is designed with **clean Jupyter notebooks** for easy understanding
